# 🐍 My First Python Repository

Antigravity AI와 연동하여 생성된 파이썬 프로젝트 저장소입니다.

## 🚀 프로젝트 구성
- `main.py`: 메인 파이썬 실행 스크립트
- `hello.py`: 첫 번째 테스트 파이썬 파일
- `requirements.txt`: 의존성 패키지 목록
- `.gitignore`: 파이썬 프로젝트 임시 파일 제외 설정

## 💻 로컬에서 실행 방법

```bash
# 1. 저장소 복제 (Clone)
git clone https://github.com/wlatmd001-collab/my-first-repo.git

# 2. 프로젝트 폴더로 이동
cd my-first-repo

# 3. 파이썬 실행
python main.py
```
